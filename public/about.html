About This Project

This project is a stock market dashboard built using Node.js, Express, and Supabase. It allows users to view their watchlist, explore historical trends, and look up stock information.

Technologies Used

  • Node.js: Server-side JavaScript runtime.
  • Express: Web framework for Node.js.
  • Supabase: Backend as a service for database and authentication.
  • Chart.js: Library for creating charts and graphs.
  • DataTables: Library for enhancing HTML tables.
